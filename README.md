# Uchechi Nwachukwu — BI Analyst Portfolio

Version 1 of Uchechi Nwachukwu's personal portfolio website, positioned for Business Intelligence Analyst and Data Analyst opportunities.

## Stack
- React
- Vite
- Responsive CSS
- Cloudflare Pages compatible

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Cloudflare Pages settings:
- Framework preset: `Vite`
- Build command: `npm run build`
- Build output directory: `dist`

## Before publishing
Update `src/data.js` with the correct:
- Email address
- LinkedIn URL
- Any future project links/content

The current project cards are intentionally marked as upcoming and do not contain fabricated results.
