# Uchechi Nwachukwu - BI Analyst Portfolio

Static HTML/CSS/JavaScript version for direct Cloudflare Pages deployment.

## Files
- `index.html`
- `styles.css`
- `script.js`
- `assets/uchechi-portrait.jpeg`

## Cloudflare Pages
Because this version is fully static, no build step is required.

Use:
- Production branch: `main`
- Build command: leave blank
- Build output directory: `/` or leave blank if Cloudflare accepts it
- Root directory: repository root

## Important
Update the email and LinkedIn placeholders in `index.html` before final launch.
